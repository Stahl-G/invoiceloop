## 1. 资格集确认轮( Nutrient 头牌)

定名:`QUALIFICATION_NARROW_2026-08-22`(以冻结日为准)。

**要回答的问题**:窄放行契约在**未曝光文档**上的零触达率。doctouch 08-18
是全曝光开发集(660 份,10.8%);结果文档 §6 明确:在资格集给出同闸定义
数字之前,「窄放行降低打开张数」不得写成产品能力。

### 1.1 语料与抽样

- 池 = 5,680 − 已曝光并集(`development_exposure_manifest.json` 560 ∪
  `sealed4_doc_list.json` 100)= **5,020 份**。协议冻结时断言此数。
- 抽样:doc_id 升序,按 `sha256(冻结盐 + doc_id)` 取最小 **200** 份。
  盐写进协议正文;冻结 commit 先于任何提取。
- 不分层抽取;strong/weak/none 三层用 `classify_broadcast_ocr` 事后分组
  报告(与 doctouch 同口径)。

### 1.2 提取(唯一 API 花费)

- 200 份 × 双模式(understand + agentic)= **400 次调用**,响应存
  `runs/qual-narrow/raw/`(`doctouch_arms.py::discover_dual_mode` 自动发现)。
- 并发 ≤ 4;失败重试 1 次;仍失败 → 记 `blocking`,不跳过、不静默缩样本
  (硬约束:负面发现即阻断)。
- 串行 ~21s/份,预计 ≤ 3h,后台跑。

### 1.3 四臂与指标

- A/B/C/D 全跑,复用 `scripts/doctouch_arms.py`;提取共享,臂零 API。
- 指标定义不变:`release_profile.document_touch_metrics`,主终点 =
  **文档零触达**;三层分开报,ALL 只作合计;真静默/口径争议照登。

### 1.4 预注册预测(冻结先于任何结果;错了照登)

| # | 预测 | 依据 |
|---|---|---|
| P1 | A 臂零触达 = 0% | 普查闸全挡,结构性锚点 |
| P2 | D 臂零触达落在 **5–20%** | doctouch 实测 10.8% 为中心的诚实先验;上轮 20–35% 预测错误,不重复 |
| P3 | C ≥ D | `release_tier1_explicit: false` 的 QA 探针只增触达 |
| P4 | 真静默 ≤ 3 | 不高于 doctouch 各臂 |
| P5 | 三闸全自动占比 15–19% | doctouch 盘上 17.1%,合取机制应复现 |

### 1.5 结果语义与顺序纪律

- P2 成立 → 「窄放行降低打开张数」升级为可主张的产品能力,带新数字;
  不成立 → 照登并保留限定句。**两种结果都进提交叙事。**
- 顺序:先跑臂、算完 200 份零触达,人再碰任何一份(§2 行走集从这里抽,
  但必须在路由指标算完之后)。
- 对外数字句沿用 doctouch §6 的限定格式,换新 n 与新数字。

## 2. ADK×HITL 协议内行走(ATA 头牌)

**一句话**:agent(Gemini,走 ADK)以协议内一等公民身份参与人工行走 ——
建议从第一槽就在场、每条账本行带完整溯源、**零权威**(不能 accept /
reject / 改任何闸)。修掉 HITL-narrow 自认混淆中的两条(中途注入、中途改
协议)。

### 2.1 与资格集的关系

- 行走集:从资格集 200 份中**确定性抽 20 份**,规则预注册:只取人队列
  ≥1 槽的文档,按 `sha256(盐2 + doc_id)` 取最小 20。
- 顺序:资格集零触达算完后再抽;行走不污染路由指标。
- 两轮独立记账,数字不拼接(与 narrow 轮纪律同款)。

### 2.2 建议生成:走前冻结,不走中途

- 20 份的建议在**任何裁决开始前**全部预生成,存盘为工件(响应原文 +
  sha256)。
- 账本每槽记:`suggestion_seen` + 工件哈希 + 模型 id + prompt/schema
  digest。复用 `hitl_adk_invoice_read.py` + `suggest.py` + 现有
  `suggestion_seen` 字段;新增仅两个溯源字段(schema 改动随协议冻结)。

### 2.3 预注册预测(错了照登)

| # | 预测 | 依据 |
|---|---|---|
| P1 | 有建议工件的槽 100% 带 `suggestion_seen` + 溯源字段 | 「有机结合」的结构性主张,可测试 |
| P2 | agree 类建议采纳率 ≥ 60% | narrow 实测 10/13 = 77%,留回落空间 |
| P3 | 行走槽中位耗时 ≤ 60s | narrow 30s / 普查 R1-S1 52s;建议不该拖慢行走 |
| P4 | 模型提出异议且人采纳改值的槽 ≥ 1 | 若 = 0,顾问层价值主张如实登记为未证明 |
| P5 | 零权威违反 | 结构保证:agent 输出只进建议工件,不进任何 gate/approve 路径 |

### 2.4 废臂条款(触发即声明)

裁决开始后:改协议文本、换模型、中途补生成建议、复查 DocILE 标注 ——
任何一条 = 臂不干净,照 narrow 轮先例如实声明。

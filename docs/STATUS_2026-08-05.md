## 1. The project's thesis (the premise for adjudication)

**Extraction correctness cannot be trusted; support relations are verifiable.** The deliverable is a
support matrix + an offline-verifiable audit bundle, not "this value is right". Any phrasing of
"improving extraction accuracy" violates the charter (ARCHITECTURE.md §1, charter six).

## 2. The system as built (all pinned by tests)

**Trunk** (M0–M4): stored-evidence zero-API pipeline — extraction (store first) → artifact registration →
evidence spans (bbox + independent OCR) → freeze transaction (draft → binding check → FC ID; the model only
writes drafts, Python assigns IDs) → six deterministic gates → support matrix → panel.

**H0 integrity** (14 invariants): no --force; runs immutable, increasing generation by generation;
execution-fingerprint replay (inputs + code + harness); adjudications bound to a full review snapshot
(6 components, including routing_report); pre-append snapshot consistency check; claim↔doc↔field triple
consistency; explicit supersession chains; orphan-adjudication flagging; cross-process flock; decided_at
ISO validation. Evidence: docs/H0_INTEGRITY_2026-08-03.md + tests/test_run_immutability /
test_review / test_adjudicate.

**H1 workbench**: stdlib http.server, 127.0.0.1, zero new dependencies; Host allowlist + Origin
check (against DNS rebinding/CSRF); full escaping; server-applied timestamps; image-reading advisory
layer (purple advisory; adopting it only pre-fills the form; frozen-rejected values get no button);
Chinese/English i18n; one-sentence gate hover explanations (fidelity-reviewed). Evidence:
tests/test_workbench.py (38 contract tests).

**C8 cross-document duplicate detection**: same number and same seller with content conflict /
duplicate submission → non-blocking finding + review queue. On its first outing it caught a true
duplicate pair in the held-out set (#18N0039311 / MORGAN COUNTY). Evidence: tests/test_crossdoc.py.

**Whole-document delivery layer**: deliverable.json is a pure projection; values come only from the
frozen ledger and the adjudication ledger (projections are not a value source — the review-81
attack-chain fix); decision semantics in six parts (accept must carry a claim / confirm_absent /
not_applicable / reject / correct / abstain); whole-document released/pending/blocked/released_with_caveats;
decision_load_for_release reported per run. Evidence: tests/test_deliver.py, test_projection_integrity.py.

**verify, four layers**: members → snapshot (recomputed from the component set recorded in the snapshot) →
binding (supersession-chain replay + decision-semantics replay) → **semantics** (projected values vs
frozen declarations; routing_report recomputed from in-bundle facts and compared slot by slot). The
honesty boundary has a pinning test: a forgery consistent throughout would pass; the anchor is the
out-of-band published bundle sha256.

**Improve Layer (v0.2 narrowed)**: policy-driven triage in routing.py (HAR-0001 byte-for-byte equivalent
to the old inline criteria, heldout rerun with zero diff); harness digest enters the execution
fingerprint; policy_accepted; deterministic hash QA sampling (5%/20% two levels); feedback event
derivation (reason_code + reviewer_confidence + combination checks + actionable);
`improve mine/propose/evaluate/promote/rollback` CLI (fully deterministic, zero model; promote requires
a human name + rationale + ISO time; basis honestly labeled evo_replay_only).
Evidence: tests/test_routing.py, test_improve.py, test_eval_norm.py;
docs/IMPROVE_LAYER_V01_IMPLEMENTATION_2026-08-05.md.

the triage's differentiation lies in operating-point safety and verifiability, not in ordering quality.

**61.2%**, document touch **100%**, decision_load_for_release **82.3%**.

prohibition.

**Live DWS, measured** (docs/LIVE_TEST_2026-08-05.md): 7 real calls; on the same PDFs, two months later,

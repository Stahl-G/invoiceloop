## 1. 项目论点(裁决的前提)

**抽取的正确性不可信,支持关系可验证。** 交付物是支持矩阵 + 可离线验证的
审计包,不是「这个值是对的」。任何「提高抽取准确率」的表述都违反宪章
(ARCHITECTURE.md §1 宪章六)。

## 2. 已建成的系统(全部有测试钉死)

**主干**(M0–M4):存盘证据零 API 流水线 —— 抽取(先存盘)→ 工件注册 →
证据片段(bbox+独立 OCR)→ 冻结事务(草稿→绑定校验→FC ID;模型只写草稿,
Python 分配 ID)→ 六道确定性门禁 → 支持矩阵 → panel。

**H0 完整性**(14 条不变量):无 --force;run 不可变逐代递增;
执行指纹重放(输入+代码+harness);裁决绑完整复核快照(6 成分,含
routing_report);append 前快照一致性检查;claim↔doc↔field 三元一致;
显式 supersession 链;孤儿裁决标记;跨进程 flock;decided_at ISO 校验。
证据:docs/H0_INTEGRITY_2026-08-03.md + tests/test_run_immutability /
test_review / test_adjudicate。

**H1 工作台**:stdlib http.server,127.0.0.1,零新增依赖;Host 白名单 +
Origin 检查(抗 DNS rebinding/CSRF);全转义;服务器盖时间戳;读图建议层
(紫色 advisory,采用只预填表单;冻结拒绝值不给按钮);i18n 中英;
门禁悬停一句话解释(保真复核过)。证据:tests/test_workbench.py(38 条契约)。

**C8 跨文档查重**:同号同卖家内容冲突/重复提交 → non-blocking finding +
复核队列。首战即在留出集抓到真重复单(#18N0039311 / MORGAN COUNTY)。
证据:tests/test_crossdoc.py。

**整单交付层**:deliverable.json 纯投影;值只来自冻结账本与裁决账本
(投影不作值源 —— 81 评攻击链修复);决策语义六分(accept 必须带 claim /
confirm_absent / not_applicable / reject / correct / abstain);整单
released/pending/blocked/released_with_caveats;decision_load_for_release
逐 run 报告。证据:tests/test_deliver.py、test_projection_integrity.py。

**verify 四层**:members → snapshot(按快照记录的成分集重算)→
binding(supersession 链重放 + decision 语义重放)→ **semantics**(投影值
vs 冻结声明;routing_report 从包内事实重算逐槽比对)。诚实边界有钉边测试:
全一致伪造会过,锚在带外公布的包 sha256。

**Improve Layer(v0.2 收窄版)**:routing.py 策略驱动分诊(HAR-0001 与旧
内联判据逐字节等价,heldout 重跑零 diff);harness digest 进执行指纹;
policy_accepted;确定性哈希 QA 采样(5%/20% 两档);feedback 事件派生
(reason_code + reviewer_confidence + 组合校验 + actionable);
`improve mine/propose/evaluate/promote/rollback` CLI(全确定性零模型,
promote 必须人名+理由+ISO 时间,basis 如实标 evo_replay_only)。
证据:tests/test_routing.py、test_improve.py、test_eval_norm.py;
docs/IMPROVE_LAYER_V01_IMPLEMENTATION_2026-08-05.md。

  1. 先把规则冻住

    实验开始前，harness、阈值、失格条件和输入指纹全部写进版本库。看到结果后不能改题。

  2. 再跑同一批证据

    六套规则读取相同 PDF、OCR、抽取结果和字段账本。HAR-0004 的重复臂逐字节一致。

  3. 最后让真值裁判

    DocILE 标注只在开箱后判断：自动放过的字段里，有没有把真实值悄悄漏掉。

3.75× 不是“准确率提高 3.75 倍”。它只表示：被排到队首的字段，比队尾更集中地包含可判问题。InvoiceLoop 测的是“先看哪里”，不是替人宣布发票一定正确。

少看 97 个，代价是漏掉 1 个。

“人工队列”指系统没有自动接受或自动确认缺失、仍要交给人处理的字段。队列变短是收益；真实字段被自动藏掉是不可接受的代价。

但静默缺席从 0 变成 1。

这些是“整套 harness”的配对效果，不是纯粹只改一个字段的药物试验。QA 抽样会因为 harness ID 改变而重新分配；HAR-0006 没增加新语义，却仍多出 4 个队列槽，正好暴露了这项混杂。

如果让 ADK 自动晋升，会怎样？

Gemini ADK 提出的 due_date 候选确实更省人，但它把“可能没有到期日”推得太远。自动晋升不是更聪明，而是把没有经过安全门的建议直接写进未来运行。

相对 HAR-0004，HAR-0007 把人工队列从 527 压到 494。

+5

多漏 5 个真实到期日

这五个日期在 DocILE 真值里都非空，不能解释成“页面本来就没有”。

ADK 只提案 → Python 算配对差 → 预注册门禁决定能否写入。

结果：候选被拒绝，没有 promotion marker。实验开箱时也没有再次调用 ADK，避免模型在看到结果后改变说法。

那 1 个漏掉的税号，是怎么发生的？

这不是模糊边界，也不是“美国发票没有 VAT”这种文化差异。它是一张 rebate form：单据类别识别对了，路由规则却没有使用这个类别。

  1. 类别识别正确

    页面写着“rebate form”，doctype 判为 credit note，字面证据通过。

  2. 抽取结果为空

    DWS understand 没有给出 seller_vat_id。

  3. 路由自动判缺失

    HAR-0004 没消费 doctype，上游空值被当成“预期不存在”。

  4. 真值证明漏了

    DocILE 标注里有真实税号 27042768；它没有进入人工队列。

这条失败给下一版一个具体方向：把 doctype 和字面证据放进 HITL 上下文与 applicability 判断，但不能让类别模型直接替人裁定字段不存在。

为什么 HITL 必须看见单据类别？

100 份未见单据里，只有 75 份被归为 invoice；其余 25 份是合同、贷项单、报价、订单、收据或无法分类。让用户每份都重新猜类别，既慢，也无法把一致口径带进下一份。

类别是上下文，不是裁决者。

doctype 检查结果为 83 pass、9 fail、4 no claim、4 unmapped。下一版可以显示类别和它在页面上的字面证据，并据此改变提问方式；但按钮预填或自动缺席仍需要新的未见数据验证。

SEALED-3 已经用完。任何由这个失败样本启发的修复，只能在开发集上实现，再交给 SEALED-4 做新的资格测试。

七道门，六道通过也不能抵消一道失败。

这些门分别检查排序、覆盖、缺失、引用、冻结和可复核性。每一道回答不同问题；通过某一道，不代表其他风险自动消失。

冻结 scorer 把每一套 harness 的 decision_load_for_release 都报成 82.8%。但同一份文件里的逐字段状态明明从 62.4% 降到了 49.4%。这说明指标实现错了，不是六套规则神奇地完全相同。

82.8%

标记为不可解释，不拿来讲结论。

根因是旧计算把策略已经确认缺失的字段又算回了人工。开箱后没有偷偷改代码再重算；修复进入下一版，SEALED-3 不负责给这项修复补考。

下一版做什么，边界已经很清楚。

这次失败没有浪费：它把“再优化一下”变成了四个可以实现、可以再次检验的具体任务。

  1. 把 doctype 接进 HITL 的解释层

    显示类别、字面证据和按类别改写的问题；不让类别模型直接预填答案。

  2. 设计带类别条件的 applicability 规则

    任何自动缺席仍保留人工探针，并先在开发数据上测静默缺席。

  3. 修正 decision load 指标

    让摘要数字尊重 policy_accepted、policy_confirmed_absent 和 release 配置。

  4. 把两件未完成的测量分开

    人类裁决准确率等 H2 臂完成；修改后的系统资格等新的 SEALED-4，不能回看 SEALED-3 自证。
